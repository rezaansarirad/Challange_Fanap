# Stack

- Python 3.12, FastAPI, pandas, httpx, pytest.
- React 18, TypeScript, Vite, Vitest, React Testing Library.
- React Hook Form for the validated upload form.
- Self-hosted Peyda FaNum (Regular/Medium/SemiBold/Bold) in `frontend/public/fonts` for Persian text and numerals.
- Docker Compose runs frontend and backend with one command.

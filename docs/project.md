# Bazarcheh Support Triage

Persian RTL dashboard for uploading daily support exports, grouping customer pain points, surfacing high-severity unanswered messages, and safely drafting replies.

## Product goals

- Trustworthy unique-message/category metrics.
- A live, SLA-ordered attention queue using Tehran business time.
- Explicit, safe, on-demand reply drafts; approval only copies text.
- A stable CLI contract for the nightly export job.
